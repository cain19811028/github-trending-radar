## About

Every day at 00:00 UTC, the radar reads [GitHub Trending](https://github.com/trending), remembers which repos have been there before, and filters out what is worth a look:

- 🆕 **New Today**: repos the radar has never seen on Trending before (🤖 = AI-related)
- 🚀 **Breakouts**: stars gained today ≥ 10% of total stars, or the repo is less than 30 days old
- 🤖 **AI Spotlight**: today's AI-related repos
- 💎 **Non-AI Gems**: today's repos that are not about AI (keyword-based, so expect a few misses)
- 📌 **On a Streak**: on Trending 3+ days in a row

Every Monday it also sums up the previous week in [weekly/](weekly/): GitHub's weekly board ranked by stars gained, rising newcomers, repos new to the radar, the ones that stayed on the board most days, and the AI share.

Each day's commit message is that day's headline: subscribe to [commits/master.atom](https://github.com/cain19811028/github-trending-radar/commits/master.atom) to get it daily.

Daily archive in [archive/](archive/), weekly reports in [weekly/](weekly/), raw data in [data/](data/), memory in [state/seen.json](state/seen.json).
